3. **Treat the CRT as semantic content.** The monitor, cables, vents, and keyboard are part of the visual argument documented by Notion, not disposable decoration. They belong in hero/poster compositions even when an isolated subject primitive is also produced.

7. **Use locked canon plus living application layers.** The Notion manifesto's boundary is a useful governance model: morphology and sigil meaning are stable references; crop, pose, field, monitor color, and campaign composition can evolve with explicit version labels.
8. **Do not claim complete Project migration.** The current evidence supports a detailed visual brief and one binary sidecar, not a mapping-preserving export. Any future Project export should be reconciled by conversation ID and retain all mapping nodes.

## Reusable methods and assets

### Three-class asset model

| Class | Definition | Recommended destinations | Do not assume |
|---|---|---|---|
| Background plate | Subject-free field, bands, grid, schematic texture, or material atmosphere | `assets/img/` source master, `assets/img/webp/` derivatives, CSS background reference | That it is safe behind text without contrast testing. |
| Subject study | Bird morphology, posture, material, or eye/face reference without a required scene | `assets/img/library/` or a reviewed private/brand asset vault | That a visible colored field means alpha transparency. |
| CRT lockup | Bird plus obsolete computer, cables, keyboard, monitor glow, and optional baked wordmark | Hero/poster/library reference; keep production text separate | That it is a logo, favicon, or reusable transparent primitive. |

### Visual grammar

1. **Silhouette:** large predatory head, hooked beak, jagged crest, layered pointed plates, long tail, heavy legs, and enlarged talons.
2. **Material:** distressed olive/bronze/gray/teal metal with etched or blueprint-like linework; avoid smooth generic mascot rendering.
3. **Warmth:** orange cybernetic eye and monitor glow are focal signal, not a full-spectrum neon palette.
4. **Field:** horizontal color strata establish categories or geological/technical layers; blueprint grid and schematic marks add protocol texture.
5. **Occupation:** the bird grips or dominates the hardware. It should read as occupying an obsolete interface, not as a decorative bird perched on a random prop.
6. **Typography:** use generated wordmarks only as layout references. Rebuild copy in approved type and keep it outside the raster master when the asset is used on the site.
